# Rockabuddy · 会听歌、会打盹、帮你看 AI 额度的桌面小同伴

Windows / Python / PySide6 的开源桌宠。内部代号 TokenSpy。

它延续自作者的「向日葵 rock 节拍器桌宠」——一个在 AI 代码补全时代就跟着音乐节拍摇摆的桌宠。这一代,她(猫头鹰娘奥尔)和向日葵一起住进你的任务栏边,一边陪你看番写码,一边帮你盯着各家 AI 服务的余量。

## 下载即用(Windows)

到 [Releases](https://github.com/Guzi2005/rockabuddy/releases) 下载 `Rockabuddy.exe`,双击即用,无需安装 Python。

- 首次运行会在 exe 旁生成 `config.json`(空服务列表);把 `config.example.json` 复制改名为 `config.json` 可直接获得一份模板。
- API Key 放同目录 `.env`(参照 `.env.example`),或用看板"连接"按钮(存入 Windows 凭据管理器)。密钥只存本地,绝不上传。

## 创新点

- **用量感知桌宠**:鼠标悬停时,各 AI 服务的余量/复活时间以光环图标绕在脑后,告急服务灰化——把"监控面板"长在了宠物身上。
- **跟着音乐真的在听**:WASAPI 回环采音(纯标准库,不碰麦克风权限),双频段包络 + 自适应峰值拾取 + **节拍相位锁(PLL)**——切分音带不歪节奏,长时间跟拍不漂移;换耳机自动跟随最响输出设备。右键菜单四种听音乐模式:
  - **节拍器**:预测拍点正中轻轻点头,卡点精确
  - **摇滚甩头**:低频重拍(鼓)触发左右交替甩头,拍间自然回落
  - **美声跟唱**:眯眼笑,身体以乐句(约两拍)为单位长音缓动,幅度随响度呼吸
  - **跟唱说话**:检测到音频就"张嘴"跟唱,无声立刻闭嘴待机(原向日葵的"师范方案")
  - **✏️ 训练 10 秒**:八字双铅笔跟着你的鼠标/键盘敲击起落(长按伏地),采完按敲击风格自动适配上面四种模式之一并标定 BPM
- **和你一起打字**:办公桌模式下侦测主人击键,左右爪交替敲键盘;贴近任务栏自动"坐下办公",拖离即站起。
- **有光标感知**:她会把身体轻轻转向你手边的光标方向,走近了她、离开她,都有细微的"注意力"变化。
- **会自己过日子**:没人理她时会伸懒腰、抖耳朵,太久没互动就原地打盹冒 Zzz,悬停/点击/击键/音乐响起都会把她叫醒;眨眼间隔随机化,偶发连眨两下。
- **「XX,启动!」**:侦测新应用/常用网站打开,取出图标高高举起(原神启动式);`快端上来罢` 还会把最近的启动记录叠成一塔捧出来。
- **有物理的小生命**:拖拽会倾斜,快速摇晃会晕(螺旋眼+歪头),松手落地有弹跳。
- **克制的同步调度**:窗口恢复倒计时本地推算、心跳只同步活跃应用绑定的服务、出错指数退避、退出前快速收尾同步——常驻但不刷接口;没有任何动画的静息时刻自动降到 ~8fps 重绘,空闲 CPU 开销极低。

## 启动

```bash
pip install -r requirements.txt
python app.py
```

或复制 `config.example.json` 为 `config.json` 后双击启动器(见下)。Windows 下建议用 `pythonw.exe` 静默运行。

## 使用

- 单击猫头鹰打开或收起看板;拖动可移动,位置会记住。
- 右键可刷新、选尺寸、切换角色(猫头鹰娘 / 向日葵)、开关各种互动与开机自启,或退出。
- 托盘菜单可以找回桌宠;重复启动会弹提示,不会开出第二只。
- 看板一排一个服务, 顶部是带**胶囊挂孔**的深色挂牌头(merged header); 动态数据都是大号直观元素: **24h 趋势火花线 + 燃烧速率(↓%/h)** + 大号剩余值/复活时间 + **三段横条**(青=剩余、橙=今日已耗、灰=此前已耗); Codex 这类多窗口配额一窗一条横条。
- 看板是**响应式**的: 打开时自动挑不遮桌宠的空位, 屏幕放不下自动收缩高度转内部滚动, 拖动桌宠后面板自动让位。
- 右键菜单**看板毛玻璃**可调透明度(Windows 亚克力), 25%~85% 五档。
- 桌宠显示有总量服务中的**最低剩余比例**,低于 30% 提醒。
- 看板平均值只统计有总量的有效服务;金额与积分不会混合相加。
- 双击手动卡片或点击明细的"更新"填写余量,总量可以留空。
- API 错误及附加说明可以悬停查看。未知数据不会当作零余量。

## 数据来源

配置保存在 `config.json`(模板见 `config.example.json`)。**密钥只存本地**:优先级为 环境变量/`.env` > Windows 凭据管理器(看板"连接"按钮)> `config.json`,任何密钥都不会进入代码仓库。

- **ZCode**:读取本机会话库(`~/.zcode/cli/db/db.sqlite`)统计今日实际 token 消耗,支持 `daily_budget_tokens` 设定每日预算(设了才有百分比/告急/复活提醒,重置点为每日零点)。没有公开配额接口,但本地数据比接口更真实。
- **Kimi**:按 Key 前缀自动分流——`sk-kimi-` 开头走 Kimi Code 会员额度接口(含周配额、滚动窗口、限流状态与会员档位),其余 `sk-` 开头走开放平台余额接口。
- **Cursor / Codex**:读本机登录态。
- **Trae 等无接口服务**:手动记账。
- 硅基流动余额接口已被官方停用(HTTP 410),卡片会明确提示,可临时手动记账。

横条上「今日已耗/此前已耗」的拆分:优先用各服务自己的精确数据(如 ZCode 的日预算),否则取 `history.jsonl` 里今日零点前最后一次同步的剩余比例做基线推算;没有历史基线时只分「剩余/已耗」两段。

## 同步机制

- 恢复倒计时由面板按各窗口 `resets_at` 本地推算,不再每分钟拉接口;窗口到期后宽限 20 秒自动补一次同步确认。
- 心跳同步每 `heartbeat_minutes`(默认 30)分钟一次,且只拉 `processes` 名单里进程正在运行的服务(`sync_only_active` 可关闭);没绑进程名单的服务照常同步。
- 出错按 `refresh_minutes` 起步指数退避,上限为心跳间隔;手动刷新始终同步全部。
- 退出应用时对活跃/到期服务做一次快速收尾同步(6 秒预算)并落盘 `usage-cache.json` 与 `sync-state.json`。

`history.jsonl` 保存比例历史;桌宠位置、大小、浮动偏好通过 QSettings 单独保存。
