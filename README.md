# Rockabuddy · 会听歌、会打盹、帮你看 AI 额度的桌面小同伴

Windows / Python / PySide6 的开源桌宠。内部代号 TokenSpy。

它延续自作者的「向日葵 rock 节拍器桌宠」——一个在 AI 代码补全时代就跟着音乐节拍摇摆的桌宠。这一代,她(猫头鹰娘)和向日葵一起住进你的任务栏边,一边陪你看番写码,一边帮你盯着各家 AI 服务的余量。

## 创新点

- **用量感知桌宠**:鼠标悬停时,各 AI 服务的余量/复活时间以光环图标绕在脑后,告急服务灰化——把"监控面板"长在了宠物身上。
- **跟着音乐真的在听**:WASAPI 回环采音 + 能量包络 onset 检测 + BPM 连续估计(纯标准库,不碰麦克风权限),节拍下沉、左右摇摆、音符粒子全部由真实音频驱动;换耳机自动跟随最响输出设备。
- **和你一起打字**:办公桌模式下侦测主人击键,左右爪交替敲键盘;贴近任务栏自动"坐下办公",拖离即站起。
- **「XX,启动!」**:侦测新应用/常用网站打开,取出图标高高举起(原神启动式);`快端上来罢` 还会把最近的启动记录叠成一塔捧出来。
- **有物理的小生命**:拖拽会倾斜,快速摇晃会晕(螺旋眼+歪头),松手落地有弹跳。
- **克制的同步调度**:窗口恢复倒计时本地推算、心跳只同步活跃应用绑定的服务、出错指数退避、退出前快速收尾同步——常驻但不刷接口。

## 启动

```bash
pip install -r requirements.txt
python app.py
```

或复制 `config.example.json` 为 `config.json` 后双击启动器(见下)。Windows 下建议用 `pythonw.exe` 静默运行。

## 使用

- 单击猫头鹰打开或收起看板;拖动可移动,位置会记住。
- 右键可刷新、选尺寸、切换角色(猫头鹰娘 / 向日葵)、开关各种互动,或退出。
- 托盘菜单可以找回桌宠。
- 桌宠显示有总量服务中的**最低剩余比例**,低于 30% 提醒。
- 看板平均值只统计有总量的有效服务;金额与积分不会混合相加。
- 双击手动卡片或点击明细的"更新"填写余量,总量可以留空。
- API 错误及附加说明可以悬停查看。未知数据不会当作零余量。

## 数据来源

配置保存在 `config.json`(模板见 `config.example.json`),API Key 通过 Windows 凭据管理器加密保存在本机,不入库、不上传。

- **ZCode**:读取本机会话库(`~/.zcode/cli/db/db.sqlite`)统计今日实际 token 消耗,支持 `daily_budget_tokens` 设定每日预算(设了才有百分比/告急/复活提醒)。没有公开配额接口,但本地数据比接口更真实。
- **Kimi**:按 Key 前缀自动分流——`sk-kimi-` 开头走 Kimi Code 会员额度接口(含周配额、滚动窗口、限流状态与会员档位),其余 `sk-` 开头走开放平台余额接口。
- **Cursor / Codex**:读本机登录态。
- **Trae 等无接口服务**:手动记账。
- 硅基流动余额接口已被官方停用(HTTP 410),卡片会明确提示,可临时手动记账。

## 同步机制

- 恢复倒计时由面板按各窗口 `resets_at` 本地推算,不再每分钟拉接口;窗口到期后宽限 20 秒自动补一次同步确认。
- 心跳同步每 `heartbeat_minutes`(默认 30)分钟一次,且只拉 `processes` 名单里进程正在运行的服务(`sync_only_active` 可关闭);没绑进程名单的服务照常同步。
- 出错按 `refresh_minutes` 起步指数退避,上限为心跳间隔;手动刷新始终同步全部。
- 退出应用时对活跃/到期服务做一次快速收尾同步(6 秒预算)并落盘 `usage-cache.json` 与 `sync-state.json`。

`history.jsonl` 保存比例历史;桌宠位置、大小、浮动偏好通过 QSettings 单独保存。
